# Store run history in the console's own SQLite database

Run history is stored server-side in a SQLite database owned by the console (next to `config.json` in the console's home directory), not in the browser's `localStorage` and not in `config.json`. `localStorage` is scoped to the browser and the server's origin port, so history would vanish when either changes, and it would put SQL text that may contain secrets outside the owner-only home directory. `config.json` is rewritten whole on every change, which suits a handful of settings but not an append-on-every-run log that needs per-target lookups and trimming. SQLite (`better-sqlite3`, already a dependency) gives cheap appends and indexed queries while keeping state in the core, so a future desktop shell inherits it unchanged.
